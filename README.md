# Smart Inventory Management System

Desktop-based inventory management application developed using Java Swing and Object-Oriented Programming principles.

---

## Features

- Product Management
- CRUD Operations
- Inventory Tracking
- File Persistence
- Inventory Reports
- Multithreading
- Swing GUI Dashboard
- JTable Product Management

- OOP Principles
