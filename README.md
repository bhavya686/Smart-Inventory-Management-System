# Smart Inventory Management System

A desktop-based inventory management application developed using Java Swing and Object-Oriented Programming principles.

## Features
- Product Management
- CRUD Operations
- File Persistence
- Reporting System
- Multithreading
- Swing GUI

## Technologies Used
- Java
- Java Swing
- File Handling
- Collections Framework
- Multithreading

## Project Structure
- model
- service
- ui
- util
- exception
- thread
